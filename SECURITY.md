# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

Security fixes are provided for the latest release of QuantEcon.py. Please upgrade to the latest release before reporting a vulnerability.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Use GitHub's private vulnerability reporting: go to the repository's **Security** tab and select **Report a vulnerability**. This opens a private advisory so the maintainers can coordinate a fix and disclosure with you before anything is made public.

Please include in your report:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue, if possible
- The version(s) of QuantEcon.py affected
- Any suggested fix, if you have one

## What to Expect

We aim to acknowledge vulnerability reports within a few business days and will work with you to confirm the issue, prepare a fix, and agree on a disclosure timeline.

## Scope

This policy covers the QuantEcon.py package. Vulnerabilities in third-party dependencies should be reported to those projects directly.
